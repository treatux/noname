## 冲突与处理原则

| 来源贡献 | 冲突/风险 | 处理 |
|---|---|---|
| 十周年 UI | 批量 override `ui/game/lib.element`、自建 hand wrapper、zoom | 不整体移植；复用上游节点与 CSS 状态类。 |
| 手杀 UI | 旧式 extension loader、`eval`、技能/进度 wrapper | 不安装扩展；只抽取可验证的表现层意图，保留原生交互。 |
| EpicFX/如真似幻/假装无敌 | Pixi/Spine、远程/动态代码、大媒体 | 排除运行时代码和骨骼；仅记录候选 UI 资源及 hash。 |
| AIoptimize/缘之空/斗转星移/无名补丁 | 规则、技能、AI、选将流程写入 | 本阶段明确不移植；若未来必须触及，先单独写差异证据。 |
| skin/动态骨骼 | 账号/皮肤包/`.skel`/`.atlas` | 明确排除，不下载、不提交、不作为 UI 验收失败原因。 |

## 交付判定

当前可称为“GitHub 1.11.7 上的可切换第一阶段 UI 适配”，不能称为“夸克完整 UI 已还原”。完成判定必须同时拥有实现提交、构建产物、原始/适配同阶段截图、真实输入与事件证据，以及规则/AI 未替换检查。所有未完成项保持公开记录，不以旧录像或 workflow 报告补齐。
