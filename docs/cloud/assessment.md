# 无名杀云端主持可行性评估（验证版）

## 结论

**现有规则引擎可在服务器 Chromium 中实际主持游戏和执行 AI。** 不是仅启动 WebSocket 消息转发服务：八人身份、八人国战、对决1v1、三人斗地主、两人单挑均有服务器房主和玩家浏览器双方自然结束证据。Android WebView 玩家接入八人身份局、断开后主持继续运行、重新点击连接恢复原玩家身份已有自动化记录；`android-touch-room.json` 中服务器与Android双方自然结算、events为空。触摸选将已录到原角色选择及确认，但触摸出牌/选目标的成功提交证据仍需补齐。

当前方案适合技术验证，不应直接承诺正式商用容量或手机流畅。完整浏览器房主开销较高，应用层响应尾延迟明显，老 WebView 和原生弹窗也有兼容问题。真实手机体验须由小主实际设备提供证据；模拟器自动化不等于实机体验。

## 源码、许可证和服务

- 上游 `libnoname/noname`，固定提交 `c2c9ae0be72e4284416f122a220f9c6081ddd768`，测试通道1.11.7；Fork `treatux/noname`，分支 `cloud-host-validation`。
- 独立项目 `/root/noname-cloud/source`，不覆盖 `/root/sgs-offline`。GPL-3.0、上游署名和许可保留；测试APK非正式发行版。
- 本地端口：18081开发页面、18089开发文件服务、18091构建文件服务、18082联机大厅。没有开放公网文件管理接口。
- 访问：通过 USB adb reverse + SSH隧道连接18082，详见 `android-test.md`。无线公网入口/WSS尚未部署，不将本机监听描述为公网服务。
- 主持位置：云端 Chromium 房主页面运行 `game.onlineroom=true`、规则事件和AI；大厅只转发消息；Android `game.online=true` 作为玩家接入，不主持房间。

## 模式覆盖

逐项清单见 `mode-inventory.json`，范围为默认十种游戏模式，不含作为入口的connect，也不承诺每个子模式/武将组合无缺陷。

| 模式 | 上游联机 | 本次代表性验证 |
|---|---|---|
| 身份 | 是 | 八人云端主持与浏览器玩家自然完成；Android接入及断开恢复 |
| 国战 | 是 | 八人云端对局双方自然完成，36个样本，events为空 |
| 对决 | 是 | 1v1换将双方自然完成；修补结算纯统计记录的isOnline2调用后回归无fatal |
| 斗地主 | 是 | 三人云端双方自然完成 |
| 单挑 | 是 | 两人云端双方自然完成 |
| 挑战 | 否 | 本地真实玩家/事件循环，无fatal；未提供connect配置，不伪称支持联机 |
| 战棋 | 否 | 本地行动/判定循环，无fatal；未提供connect配置 |
| 塔防 | 否 | 初始gameDraw使用旁观占位节点崩溃；最小调用修补后到第四轮，无fatal |
| 炉石 | 否 | 本地召唤/行动循环，无fatal；未提供connect配置 |
| 乱斗 | 场景依赖 | 默认幻化之战实际开始身份规则循环，无fatal；非仅打开菜单，不证明乱斗菜单联机可用 |

限制证据来自上游 `lib.mode[mode].connect` 声明与实测 JSON。本地-only模式如要搬到云端，需新增状态同步/玩家输入适配，不属于本次最小云端联机复用的通过项。除五种联机代表局外，本地测试主要验证启动和运行，不声称完整自然结束。

## 修补范围与 Android

1. 对决 `game.over` 遍历players/dead/additionaldead时，additionaldead包含纯{name,stat}；可选调用 `isOnline2?.()` 避免将统计记录当Player。
2. 塔防初期game.me为旁观节点；gameDraw从实际新增角色开始，避免遍历未连接的玩家链。
3. Debug MainActivity加载内置资源，开启WebView调试。
4. 可选 `NONAME_TEST_SILENT=1` 省略APK音频；`NONAME_TEST_PACKAGED=1` 只读内置资源，不再要求SAF第二套游戏目录。默认上游SAF未改变；只读测试不支持扩展写入与导出。
5. 可选内置资源测试变体把已知外部模块名解析到importmap对应URL，并修正HTML裸模块src，避免WebView113实际捕获的vue解析失败。只改生成资源，不重写规则引擎。
6. 资源变体切换清理生成APK增量ZIP状态。旧增量包虽删除音频仍约1.309GB，当前条目压缩仅约657MB；清理后最终约628MiB。

最终兼容变体构建成功，`android-resolved-install.log` 为流式安装Success。当前SHA256记录 `android-resolved-sha256.txt`；包ID `com.libnoname.noname`，测试debug签名、minSdk26/targetSdk36，已有另一项目app未卸载。

Android初始启动捕获系统及应用ANR，原生ANR/GPL弹窗阻塞CDP；WebView113不支持完整Browser上下文协议，使用最小Page CDP适配。清空测试初始reconnect/tmp_room配置避免前一房间自动重入造成ui.rooms竞态；正式恢复测试保留原玩家标识。启动ANR不能归因全部给游戏，也不能忽略：当前模拟器背景占用约4.8GiB、400%以上单核CPU，需在真实手机重新验证。

## 性能测量方法与环境

- 服务器：KVM Linux，16个逻辑CPU，Intel Xeon Gold6133@2.50GHz，约15GiB内存，4GiB swap。`hardware-cpu.txt`、`hardware-memory.txt`、`hardware-kernel.txt`保存原始信息。
- Node22.23.3、pnpm10.34.6、JDK21、Android SDK36；Playwright服务器Chromium与Android WebView113。
- 每房间：一个独立主持Chromium进程树＋一个独立测试玩家Chromium进程树，八人身份，房主AI和玩家托管，标准/神话/界限突破武将包。
- `SystemInfo.getProcessInfo`识别browser根PID，Linux `/proc/<pid>/stat`按后代进程累积CPU/RSS。100% CPU代表一个逻辑核；RSS会重复计共享页，**不是PSS或独占物理内存**。
- 单房间有效采样59次、约177.8秒；三房间62次、约177.2秒。目标间隔2秒，遍历开销/调度使实际间隔不均。忽略首个无CPU差分点。
- 背景模拟器仍运行（用户既有设备，不为测试销毁），本次不含Gradle构建重负载；测试玩家与模拟器消耗可争用宿主资源。边界比先前混合采样明确，但**不是隔离宿主、固定随机种子、无噪声容量基准**。
- 网络：各游戏WebSocket逻辑UTF-8载荷字节。未包含HTTP资源下载、TLS/IP头、NIC流量；主持转发广播开销计入应用载荷，不等于单手机链路字节数。
- 响应：每2秒发送应用层cloudMeasure消息，经大厅转发到主持handler并回传执行，客户端performance.now计RTT。包括客户端/主持JS队列、序列化与WS调度；**不是纯网卡ping，也不是实际点击到出牌完成延迟**。
- AI：包裹ai.basic.chooseButton/chooseCard/chooseTarget，保持参数/返回值不变，记录同步决策墙钟。含嵌套调用，不能直接相加当总CPU；不覆盖所有技能自定义AI。
- 事件：GameEvent.loop对phase/useCard/damage/chooseToUse记录含子事件的墙钟，包含等待与动画，不能相加或当纯AI时间。
- 动画：game.delay实际Promise完成时间＋要求延时，后者最快速度常为33.3ms；前者还含事件循环拥塞，不代表GPU帧时长。未采集真实手机FPS。

## 建议后续架构

1. 短期保留原引擎，每房间独立长期Chromium房主＋受控会话生命周期/日志；客户端仅渲染与输入。只使用上游联机模式，保留错误边界。
2. 大厅和房间监督器分离，监督器可用Go；崩溃检测、房间PID资源限制、进入/重连状态持久化属于后续工程，**本次未实现账号/付费/排行榜**。
3. 优先减少服务器房主无用渲染/音频/动画等待，做规则一致性回归和受控A/B测量；不可直接删等待破坏引擎事件语义。
4. 测试玩家搬到外部真实设备，并在无模拟器/构建负载的窗口重测；增加技能级慢调用与事件循环lag、协议消息时序，区分应用队列与传输RTT。
5. 单节点容量只按实际多房间持续负载、延迟目标和内存余量验证，逐步加房间；本报告只证明测试过1和3房间，不承诺可用最大容量。
6. 若长期目标高并发，逐步抽取纯规则/可重放状态机而非立即重写全引擎。保留现有规则测试与模式矩阵，新增本地only模式同步属于独立范围评估。

## 尚未满足与验收边界

- Android最终自然结算已通过（`android-touch-room.json`），触摸选将已有记录；触摸卡牌后并未记录成功提交与目标选择，不以触摸次数冒充完成出牌，继续补齐操作用例。
- 真手机流畅性待小主实测；缺少实机型号、FPS/录屏、网络、点击反馈证据，明确保持待验证。
- 无线公网WSS未部署；ADB/SSH是可复现测试路径。`HOST_ONLY=1` 主持脚本提供长期房主进程与独立entry.json，等待玩家加入后开始并持续托管；不是生产级崩溃恢复daemon。
- 静音只读APK不评价完整音效、扩展安装或正式更新；真实机型/WebView兼容仍待扩展验证。
- 工作目标保持运行，不能将上述未验证项降低标准或提前记为完全完成。
